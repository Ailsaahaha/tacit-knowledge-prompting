这里放的是完整对话记录，不是摘要。每个示例都包含：**原始问题 → 只问一层（普通回答）→ 两层回答 → 事后复盘**。

## 怎么看这些示例

**重点看第二层。** 第一层（显性层）谁都能给——数据、定义、可验证的推理。真正的差别在第二层：它敢说「理由说不清，但感觉是……」，并且**明确标注不保证对**。

如果你看到某个示例的第二层写得很确定、很有条理、像一篇小论文——那不是默会层，那是把第一层换了个说法。**真正的默会层特征是承认不确定性。**

## 关于真实性

- 示例 01 来自真实业务数据（公众号后台的阅读量对比），不是编的。
- 示例 02、03 是按模板现场生成的输出，**没有事后润色**——包括里面「说不清」的部分也保留原样。它们展示的是方法能输出什么，不是「正确结论」。
- 所有示例里的判断都**只代表当时的直觉**，不构成建议。用的时候请配上对照组。

## 自己跑一遍

```
[你的问题]

请按波兰尼的默会知识两层回答：
1. 显性层：你能直接说出来的（数据、定义、可验证的推理）
2. 默会层：你「知道但说不清」的部分——经验判断、直觉、情境感

不要回避默会层。那才是真正的判断。
说不清就说「说不清」，不要硬编一个理由。
```
